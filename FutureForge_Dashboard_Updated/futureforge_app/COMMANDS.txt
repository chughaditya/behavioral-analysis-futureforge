5️⃣  CUSTOM PREDICTION (Your own values)
================================================================================

python

from hybrid_pipeline import HybridPredictor

predictor = HybridPredictor(
    dataset_path="backend/data/dummy_behavior_data.csv",
    artifact_dir="backend/data/artifacts"
)

result = predictor.predict({
    "study_hours": 6.5,      # Change these values
    "sleep_hours": 7.8,
    "screen_time": 3.2,
    "mood": "focused"        # Options: focused, balanced, tired, stressed
})

print(f"Score: {result['future_score']}")
print(f"Risk: {result['risk']}")
print(f"Confidence: {result['confidence']}%")

exit()

🎯 EXPECTED OUTPUTS
================================================================================

Score (0-100):
  🔴 0-54   = Low productivity (needs attention)
  🟡 55-74  = Medium (room to improve)
  🟢 75-100 = High (on track)

Risk:
  🟢 low    = Score ≥ 75
  🟡 medium = Score 55-74
  🔴 high   = Score < 55

Confidence:
  72-98% = How reliable the prediction is

================================================================================
❌ TROUBLESHOOTING
================================================================================

Q: "No module named 'tensorflow'"
A: Run: pip install tensorflow

Q: "Dataset not found"
A: Make sure you're in the FutureForge_ML_Model folder
   Check that backend/data/dummy_behavior_data.csv exists

Q: "No such file or directory"
A: Make sure you extracted the zip file properly
   cd FutureForge_ML_Model

Q: Predictions are slow on first run
A: First run trains models (~2-5 seconds). Next runs are fast (<200ms)
