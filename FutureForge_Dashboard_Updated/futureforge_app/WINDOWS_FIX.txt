  → Make sure you extracted the zip
  → Check that backend/data/dummy_behavior_data.csv exists

  → NORMAL! First run trains models. Future runs are instant.

ERROR: "python command not recognized"
  → Try: python --version
  → If that doesn't work, reinstall Python from python.org
